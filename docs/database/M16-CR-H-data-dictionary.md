### fn_notification_dispatch_update_retry_outcome
**Type:** Write (VOLATILE DEFINER — INTERNAL, no HTTP route)
**Purpose:** Updates notification_dispatch_log row after retry attempt. On success: status='sent'. On failure: retry_count++, next_retry_at = NOW() + backoff(retry_count), status='pending_retry' (or 'final_failed' at retry_count=5).
**Backoff schedule:** 1m → 5m → 30m → 2h → 8h → final_failed. NOTIFICATION_RETRY_BACKOFF_SCALE_SECONDS env accelerates to 1s/5s/30s/120s/480s for test/E2E.
